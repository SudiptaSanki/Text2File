# Supported Formats

## Release 0.1

- TXT: plain text download.
- Markdown: simple Markdown download.
- HTML: sanitized, printable standalone document.
- Word DOCX: editable Word document with basic text styling.
- Word-compatible DOC: HTML document saved with a `.doc` extension.
- PNG: image export of the canvas.
- PDF: browser print dialog, including Save as PDF where supported.

## Planned

- Higher fidelity DOCX styling and image embedding.
- Direct vector PDF generation.
- Template-based documents.
- Import from TXT, Markdown, and HTML.
- Optional image support with strict size limits.
